AWL Sublist 通关

什么是 AWL ？为什么背它？

AWL（Academic Word List，学术词汇表）由新西兰惠灵顿维多利亚大学 Averil Coxhead（2000）编制，是雅思/托福圈公认的头号学术词表。共 570 个词族，按频率分 10 个 Sublist（1–9 各 60 词，第 10 为 30 词）。Sublist 1 最高频、最该先背，已在本包全部完成。

参考来源（权威免费）：维多利亚大学官网 wgtn.ac.nz/lals/resources/academicwordlist；EAP Foundation eapfoundation.com/vocab/academic/awllists。原稿 PDF：AWL_Academic_English_UK.pdf（见原始资料）。

我们的记忆方法（核心心法）

一句话原则：拆词根 + 造画面 + 成串记同族词。死记字母永远背不牢，认识词根这把「钥匙」，后面越背越快。

  • 拆分法：把单词拆成熟悉的词根/前缀/后缀（如 dis+tribute = 分开给 = 分发）
  • 谐音法：用读音编中文画面（如 sector → 切披萨切出一块 → 部门/扇区）
  • 造句法：放进语境区分易混词（如 estimate / assessment）
  • 成串法：记一个词根，带走一串同族词（如 fin → final / finish / define / definition）

    第 1 组 · 经济类（9 词）

    单词释义记忆方法
    financial财政的 / 金融的词根 fin=了结/边界（final、finish）。钱要「结算 fin」→ 金融财政。带记：final、define
    economic经济的eco(家)+nom(管理) → 「管家之道」=经济
    income收入in(进)+come(来) → 「进来的钱」
    benefit好处 / 利益bene(好)+fit(做) → 「做得好」=好处
    labour劳动 / 劳工联想 collaborate / elaborate → labor=出力
    export出口ex(向外)+port(港口) → 「从港口往外运」
    distribution分布 / 分发dis(分开)+tribute(给予) → 「分开地给出去」。带记：contribute、attribute
    percent百分比per(每)+cent(百) → 「每一百」
    sector部门 / 领域 / 扇区词根 sect=切。切披萨切出一块=sector。带记：section、insect

    ② 二台电脑如何「接上记忆、继续任务」

    重要：WorkBuddy 的「记忆」和「技能」存在本机特定路径。换电脑后需手动把 记忆与工作流/ 里的文件放回对应位置，AI 才能「想得起」之前的约定。

    步骤 1 · 复制整个迁移包

    把 AWL背词_迁移包/ 整个文件夹拷到二台电脑任意位置（U 盘 / 网盘 / 微信文件传输助手均可）。本文件 AWL学习总览.html 可独立使用，无需任何依赖。

    步骤 2 · 恢复「记忆」（让 AI 记得你）

    若二台电脑也装了 WorkBuddy，把以下内容放回：

    记忆与工作流/2026-08-01.md → 复制到 <你的Workspace>/.workbuddy/memory/2026-08-01.md 记忆与工作流/vocab-memory-batch/ → 复制到 C:/Users/<你>/.workbuddy/skills/vocab-memory-batch/

    放回后，新对话里只要说「继续背 AWL」「第7组 / Sublist 2」，AI 就能接着节奏走（讲解→记录本→图片→发音网页/有道文件）。

    步骤 3 · 继续加单词（可选，需 Python）

    若要继续往后背（如 Sublist 2），改 原始资料/gen_youdao_and_audio.py 里的 words 列表加上新词，重跑即可重新生成发音网页 + 有道文件：

    python gen_youdao_and_audio.py

    Pillow 仅生成 PNG 图卡时需要（Python + pip install Pillow）。发音网页和有道文件仅需 Python 标准库。

    步骤 4 · 网易有道单词本导入（复习发音）

    1. 电脑端：有道词典 → 左侧「单词本」→ 齿轮「导入/导出」→ 选 有道单词本导入_AWL全部.xml
    2. 手机端：先试 .xml，失败换 .txt（部分版本路径：「我的」→「单词本」→「导入」）
    3. 导入后每个词可点发音、切卡片/复习模式（有道真人发音为在线现查，拼写对即可）
    4. 记得登录有道账号，否则卸载会丢数据
